
# NewsFeedApp

NewsFeedApp is an Android news application developed in **Kotlin** as part of an academic mobile application development project.

The project focuses on Android application development, working with news data from an external API, and organizing application logic for a mobile environment.

## Technologies Used

- **Programming Language:** Kotlin
- **Platform:** Android
- **Development Environment:** Android Studio
- **Data Source:** News API
- **Version Control:** Git

## Project Highlights

- Android mobile application development
- Integration with an external news API
- Retrieval and presentation of news content
- Mobile application architecture and data handling

## Academic Project

Developed as part of university coursework at the **Faculty of Electrical Engineering, University of Sarajevo**.
